# Portfolio — Francisco Rodriguez Lucero

Portfolio personal de diseño visual y motion graphics.

## Stack
- HTML + CSS + JS vanilla (sin dependencias)
- Fuentes: Google Fonts (Barlow Condensed + Barlow)
- Videos: Google Drive embed
- Imágenes: Google Drive thumbnail API
- Avatar 3D: frames PNG embebidos en base64 con animación scroll-driven
